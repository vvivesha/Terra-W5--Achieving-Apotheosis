# Terra-W5--Achieving-Apotheosis

#What is this??
A game about surviving as a turtle. Didn't quite get the chance to include motivational text about striving to achieve greater "heights" to personal accomplishments, if time allows. 
- This game was made with Python Turtl! The obstacles move down and the player moves sideways, bound to the bottom of the screen on a horizontal axis.

## You were unconscious, andddd surprise! You've awaken as a turtle.

## As your eyes finally open, you stare into a gray haze. OH NOOO THERE'S LAVA AND IT'S GONNA LAND ON YOU!! QUICK-- runnnnnnnn

# How to get it:
- Navigate to this project's GitHub Release page
- follow the instructions on the release page's description
- Orrr: Here are the instructions, below:

- download main.exe
- open it up in FIle Explorer
- play the game!
- follow GitHub Release's instructions for if you are stuck on a blue "Windows Projected Your PC" screen.

# How to play: 
- Left and Right arrow keys to move
- need a little boost? Press the spacebar for x3 movement (once, and only left/right. Use left/right arrow keys to use the boost!)
   - Beware! There's a 3-second cooldown on the spacebar's bosoter.
- dodge the red blocks of lava as they fall! See how many levels you can reach :)
